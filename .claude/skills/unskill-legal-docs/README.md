# Unskill Legal Documents - Análisis y Generación de Documentos Legales

## Descripción General

**Unskill Legal Documents** es una skill especializada para análisis comprehensivo de documentos legales, leyes, regulaciones y sentencias, con capacidad de generar informes legales profesionales y documentos pertinentes.

Esta skill es ideal para:
- **Abogados y profesionales legales** que necesitan análisis rápido de documentos
- **Empresas** que requieren cumplimiento normativo
- **Equipos de contratos** que necesitan identificar riesgos
- **Consultores de conformidad** que generan reportes de auditoría
- **Equipos de operaciones** que necesitan entender obligaciones legales

## Capacidades Principales

### 1. Análisis de Documentos Legales
- **Análisis integral de contratos**: identificación de términos clave, obligaciones, derechos
- **Extracción de información**: localización rápida de cláusulas específicas
- **Evaluación de riesgos**: identificación de provisiones problemáticas
- **Matriz de riesgos**: priorización de problemas por gravedad

### 2. Interpretación Legal
- **Análisis de estatutos**: explicación de requisitos normativos
- **Investigación de casos**: síntesis de jurisprudencia relevante
- **Investigación de regulaciones**: identificación de requisitos de cumplimiento
- **Interpretación de doctrina**: análisis de principios legales aplicables

### 3. Generación de Documentos Legales
- **Memorándum legales**: análisis detallado de cuestiones legales
- **Reportes de cumplimiento**: evaluación de conformidad normativa
- **Resúmenes ejecutivos**: síntesis clara para stakeholders
- **Recomendaciones fundamentadas**: acciones específicas recomendadas

## Casos de Uso

### Caso 1: Revisión de Contrato Antes de Ejecución
**Situación**: Empresa recibe contrato de proveedor con términos complejos.

**Proceso**:
1. Subir documento para análisis
2. Skill identifica cláusulas críticas
3. Genera matriz de riesgos
4. Proporciona recomendaciones de negociación

**Resultado**: Decisión informada con riesgos identificados

### Caso 2: Evaluación de Cumplimiento Normativo
**Situación**: Empresa necesita verificar cumplimiento con nueva regulación.

**Proceso**:
1. Proporcionar regulación aplicable
2. Skill identifica requisitos específicos
3. Evalúa prácticas actuales
4. Genera plan de remediación

**Resultado**: Plan accionable para cumplimiento

### Caso 3: Generación de Memorándum Legal
**Situación**: Equipos internos necesitan análisis legal de práctica propuesta.

**Proceso**:
1. Presentar cuestión específica
2. Skill realiza investigación
3. Genera memorándum con análisis
4. Proporciona conclusiones y recomendaciones

**Resultado**: Documento de referencia autorizado

## Cómo Usar

### Invocación de la Skill
```bash
/unskill-legal-docs [pregunta o tarea específica]
```

### Ejemplos de Comandos

1. **Análisis de Contrato**:
   ```
   /unskill-legal-docs Analiza este contrato de servicios e identifica los 5 riesgos principales
   ```

2. **Cumplimiento Normativo**:
   ```
   /unskill-legal-docs ¿Cuáles son los requisitos clave de la GDPR para recopilación de datos?
   ```

3. **Memorándum Legal**:
   ```
   /unskill-legal-docs Genera un memorándum sobre si nuestra práctica de [X] cumple con [Y] regulación
   ```

4. **Análisis de Jurisprudencia**:
   ```
   /unskill-legal-docs Explica la importancia de [caso clave] para [materia legal]
   ```

## Entradas Típicas

### Documentos a Analizar
- Contratos (MSA, NDA, Acuerdos de servicios)
- Estatutos y regulaciones
- Sentencias y decisiones judiciales
- Políticas y procedimientos internos
- Documentación de cumplimiento

### Información a Proporcionar
- **Contexto**: ¿Por qué necesita este análisis?
- **Partes**: ¿Quiénes están involucrados?
- **Jurisdicción**: ¿Qué ley aplica?
- **Enfoque**: ¿Qué aspectos son más críticos?
- **Urgencia**: ¿Cuál es el timeline?

## Salidas Esperadas

### Formatos de Reporte
- **Resumen ejecutivo**: síntesis de 1-2 páginas
- **Análisis detallado**: documento completo con detalle
- **Matriz de riesgos**: tabla con priorización
- **Plan de acción**: pasos recomendados con timeline
- **Memorándum legal**: análisis formal con citas

### Nivel de Detalle
- **Ejecutivo**: alto nivel, puntos clave
- **Profesional**: detalle técnico, análisis completo
- **Experto**: exhaustivo, con tratamiento de casos límite

## Limitaciones Importantes

⚠️ **Esta skill NO es un sustituto para asesoramiento legal profesional.**

- No es abogada ni proporciona asesoramiento legal formal
- No puede ser citada como autoridad legal en tribunales
- Requiere revisión por abogado calificado antes de decisiones críticas
- Las interpretaciones son basadas en información proporcionada (puede ser incompleta)
- La jurisdicción y leyes aplicables pueden cambiar

**Recomendaciones**:
- Consulte abogado calificado para asuntos críticos
- Verifique conclusiones con fuentes originales
- Mantenga actualización de cambios normativos
- Documente todas las conclusiones

## Mejores Prácticas

1. **Completes**: Proporcione documento completo incluyendo anexos
2. **Claro**: Especifique claramente qué necesita saber
3. **Contexto**: Explique el contexto comercial relevante
4. **Verificación**: Verifique conclusiones antes de actuar
5. **Documentación**: Mantenga registros de análisis y decisiones
